# 数据类型与来源速查

| 类型 | 原始 RomFS 相对路径 | 已存在结果或解析器 |
|--|--|--|
| 种族值与特性 | `bin/pml/personal/personal_total.bin` | `parsed/bin/pml/personal/personal_total.bin.json` |
| 进化 | `bin/pml/evolution/evo_*.bin` | `parsed/bin/pml/evolution/*.json` |
| 招式参数 | `bin/pml/waza/waza*.wazabin` | `parsed/bin/pml/waza/*.json` |
| 等级习得 | `bin/pml/waza_oboe/wazaoboe_total.bin` | `Learnset8`，每条 0x104 字节 |
| 遗传招式 | `bin/pml/tamagowaza/` | `parsed/bin/pml/tamagowaza/*.json` |
| 训练家队伍 | `bin/trainer/trainer_poke/` | `parsed/bin/trainer/trainer_poke/*.json` |
| 野生遭遇 | `bin/archive/field/resident/data_table.gfpak` | `EncounterArchive`，容器已拆 |
| 固定遭遇 | `bin/script_event_data/event_encount_data.bin` | `EncounterStaticArchive` |
| 礼物/交换 | `bin/script_event_data/add_poke.bin` / `field_trade.bin` | `GiftArchive` / `EncounterTradeArchive` |
| 巢穴/奖励 | `data_table.gfpak` 内 `nest_hole_*.bin` | Nest schema |
| 道具定义 | `bin/pml/item/item.dat` | `Item8`，尚需完整实测导出 |
| 商店 | `bin/appli/shop/bin/shop_data.bin` | `ShopInventory` |
| 多语言名称 | `bin/message/<语言>/common/*.dat` | `parsed/bin/message/` |
| 函数 RVA | `v1.3.2/0/sword_main` / `shield_main` | 尚无经证实的统一地址表 |

来源：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Game/File/GameFileMapping.cs)。

**注意：** 源文件路径定位 ≠ 文件字段验证 ≠ 运行时函数地址验证；各自需要独立证据。
