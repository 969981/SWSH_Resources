# 固定遭遇、锁闪、IV/EV 与 PID

固定遭遇：`event_encount_data.bin` → `EncounterStaticArchive`。
礼物：`add_poke.bin` → `EncounterGiftArchive`。
交换：`field_trade.bin` → `EncounterTradeArchive`。

字段含 `Species,Form,Level,ShinyLock,Nature,Gender,Ability,HeldItem,IV_HP/ATK/DEF/SPE/SPA/SPD,Move0..3`；不同结构部分字段略异，依据具体 schema 导出，不能直接套用同一布局。

`Shiny` 业务枚举定义为 `Random=0,Always=1,Never=2`；但各表的 `ShinyLock` 数据类型不同，必须检查它们的实际枚举与解释代码、样本值，**不可直接假定原始值全表通用**。野生遭遇的锁闪多涉及执行逻辑，单靠 `EncounterArchive` 不足以判断。

**个体值**：静态/训练家表的固定 IV 不等于野外随机生成的最终 IV。巢穴的 `FlawlessIVs` 表示保底 V 个数配置，与完整的六维 IV 不同。

参考 [[15-锁闪函数调查单]]。[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/FlatBuffers/SWSH/Schemas/EncounterStaticArchive.fbs)。
