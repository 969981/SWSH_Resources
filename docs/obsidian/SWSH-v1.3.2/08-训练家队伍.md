# 训练家等级、IV/EV、技能与道具

已解析：`parsed/bin/trainer/trainer_poke/trainer_poke_NNN.bin.json`。每槽：`species,form,level,heldItem,nature,ability,gender,dynamaxLevel,canGigantamax,shiny,moves[4],ivs[6],evs[6]`。

联动文件：`bin/trainer/trainer_data/`（训练家元数据）与 `bin/trainer/trainer_type/`（职业/图标等）。编号应通过同一 trainer ID 对应，而非按目录排序配对。

IV 与 EV 顺序按导出器 `HP,ATK,DEF,SPA,SPD,SPE`；`Learnset`、静态遭遇对象等内部部分结构的顺序可能不同，合并前要明确排列。示例查看 `trainer_poke_004.bin.json`。源码：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.SWSHDump/Program.cs)。
