# 极巨巢穴、活动及掉落奖励

巢穴包：`data_table.gfpak` 内 `nest_hole_encount.bin`、`nest_hole_drop_rewards.bin`、`nest_hole_bonus_rewards.bin`；以及配信 `NestHoleDistributionEncounterArchive` 等相关结构。

`EncounterNestArchive`：`TableID,GameVersion,Entries[]`；条目 `Species,Form,LevelTableID,Ability,IsGigantamax,DropTableID,BonusTableID,Probabilities,FlawlessIVs`。

等级表 `NestHoleLevelArchive` 用 `TableID → MinLevel/MaxLevel`；奖励表 `NestHoleRewardArchive` 用 `DropTableID/BonusTableID → Items[]`，活动表另有 `ShinyLock,Nature,Move0..3` 等字段。以引用 ID 做 JOIN，不能把 ID 当作数组下标。

[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/FlatBuffers/SWSH/Schemas/EncounterNestArchive.fbs)。
