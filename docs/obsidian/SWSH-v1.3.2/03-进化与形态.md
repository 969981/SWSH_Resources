# 进化与形态

原始路径 `bin/pml/evolution/evo_NNN.bin`，已解析到 `parsed/bin/pml/evolution/evo_NNN.bin.json`。每一记录包括 `slot,method,argument,species,form,level`，这些字段分别代表分支、进化方法枚举、参数、目标种族/形态、等级限制（如适用）。

**错误避免：** `argument` 不一定是道具 ID；先查 `EvolutionSet8` 与方法枚举，只有方法确定后才解释参数。源文件编号代表索引而不一定与形态/物种号完全等价；要通过 Personal 形态映射复核。保留无效空条目但不要当作实际进化。
