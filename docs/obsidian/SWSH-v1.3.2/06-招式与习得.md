# 招式、等级习得、遗传与 TM/TR

- `bin/pml/waza/wazaNNNN.wazabin` → Waza FlatBuffer，已有 `parsed/bin/pml/waza/wazaNNNN.wazabin.json`，字段：`type,category,power,accuracy,pp,priority,target,critStage,hitMin,hitMax,inflict`。
- `bin/pml/waza_oboe/wazaoboe_total.bin` → `Learnset8`：每个 personal 索引 0x104 字节；每个条目由 little-endian 16-bit move + 16-bit level 组成，遇终止符结束。
- `bin/pml/tamagowaza/` → 蛋招式/遗传招式；须保留 `formTableIndex` 和 `moves`。
- `personal_total.bin` 的 TM 位图始于记录相对 0x28，TR 位图 0x3C；TM 128 bits，TR 128 bits（兼容性，不是技能本身）。

完整字段 schema：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/FlatBuffers/SWSH/Schemas/Waza.fbs)，升级招式：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Structures/Learnset/Learnset8.cs)。
