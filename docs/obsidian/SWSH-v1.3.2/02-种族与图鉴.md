# 图鉴、种族值与宝可梦特性

1. 读取 `bin/pml/personal/personal_total.bin`，校验长度能被 `PersonalInfo8SWSH.SIZE=0xB0` 整除。
2. 使用 `PersonalTable8SWSH` 导出 `index/speciesModelId/form/present/HP/ATK/DEF/SPA/SPD/SPE/Type1/Type2/CatchRate/Ability1/2/H`。
3. 导出的 index 是 **personal 行索引**，不保证每行 index 就是全国图鉴号；形态另有 `FormStatsIndex` / `FormCount`，必须交叉核对。
4. 链接简中 `bin/message/Simp_Chinese/common/` 的宝可梦名称 DAT；ID 映射以解析器的明确名称表/键为准，不按行号盲目对应。

已提交原 JSON：[personal_total.bin.json](https://github.com/969981/SWSH_Resources/blob/master/Unpack/v1.3.2/parsed/bin/pml/personal/personal_total.bin.json)，另有基于它生成的 `Unpack/v1.3.2/catalog/species_personal.csv`。

结构：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Structures/Personal/Info/PersonalInfo8SWSH.cs)。
