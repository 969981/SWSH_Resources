# 巢穴关联键与字段

| 来源 | 主字段 | 关联 |
|--|--|--|
| EncounterNestArchive | TableID,GameVersion,Entries | 每条 Entry 的 LevelTableID、DropTableID、BonusTableID |
| NestHoleLevelArchive | TableID,Levels[] → MinLevel/MaxLevel | LevelTableID |
| NestHoleRewardArchive | TableID,Entries[] → ItemID,Values[] | DropTableID/BonusTableID |
| NestHoleDistributionEncounterArchive | EntryIndex,Species,Form,Level,ShinyLock,FlawlessIVs,Nature,Move0..3 | 活动配信结构，数值可能区别普通巢穴 |

**注意：** `Probabilities` 是多条件权重，是否对应星级、版本或具体活动须对照实测；`FlawlessIVs` 是保底个体值位数，不是六维数组；一般的 IV 随机生成不能仅凭这张表恢复。
