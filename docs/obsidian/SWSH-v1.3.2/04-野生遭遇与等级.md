# 野生遭遇与等级

主要源：`bin/archive/field/resident/data_table.gfpak`；提取结果：`Unpack/v1.3.2/extracted/bin/archive/field/resident/data_table.gfpak.files/`。

pkNX 在 `EditorSWSH.PopWildEdit` 中：分别读取 `encount_symbol_k.bin`、`encount_k.bin`（剑）；`encount_symbol_t.bin`、`encount_t.bin`（盾），并使用 `FlatBufferConverter.DeserializeFrom<EncounterArchive>`。

字段：`EncounterArchive.EncounterTables[] -> ZoneID,SubTables[]`；子表 `LevelMin,LevelMax,Slots[]`；槽 `Probability,Species,Form`。等级区间属于子表而非每个槽单独字段。子表分区与天气、模式的关系必须通过游戏实测及编辑器 UI 对照，不要凭下标硬编码。

`data_table.gfpak.files` 当前以成员索引 + 路径 Hash 命名；要关联到上述文件名，优先调用容器的 `GetDataFileName` 而不是猜 Hash。参考：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.WinForms/MainEditor/EditorSWSH.cs) 和 [查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/FlatBuffers/SWSH/Schemas/EncounterArchive.fbs)。
