# 固定遭遇、礼物与交换 Schema

`EncounterStaticArchive.fbs`: `EncounterID,EncounterScenario,Species,Form,Level,ShinyLock,Nature,Gender,Ability,HeldItem,DynamaxLevel,CanGigantamax,IV_*,EV_*,Move0..3`。

`GiftArchive.fbs`: `EncounterGift` 包含蛋标志 `IsEgg`、种族、形态、等级、球种、OT 名称键、回忆、锁闪、性格、IV 等。

`EncounterTradeArchive.fbs`: `EncounterTrade` 包含 `RequiredSpecies/RequiredForm/RequiredNature`（所需交换物）、`Species/Form/Level/ShinyLock/IV/AbilityNumber/Relearn1..4`（取得宝可梦）。

先用每个结构专属 schema 分别导出，枚举值以源码判断；存在未知字段时保留 Field/Raw，不要清理。

[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/FlatBuffers/SWSH/Schemas/EncounterTradeArchive.fbs)。
