## 原版 Alpha 独立样本复核
实际读取 v1.3.2/1/bin/appli/icon_type/bin/type_dummy_sch.arc，解析 SARC/BNTX 指针和 GOB，独立标量计算 BC5 第二 BC4 block 与 BC1 punch-through 的 Alpha（BC4 插值向下取整；并非双解码器一致性结论）。36 张纹理：

| 格式 / selector | 数量 | Alpha=0 像素 | 1..254 | Alpha=255 |
|---|---:|---:|---:|---:|
| BC5 / 2,2,2,3 | 18 | 46194 | 5388 | 22146 |
| BC1 / 2,3,4,5 | 18 | 0 | 0 | 158400 |

BC5 18 张 64×64 全部有半透明像素；例如 typeIcon_00_normal_00^t 的 Alpha=0/partial/full 为 2520/295/1281。原始第二通道作为 Alpha，不可当作普通 RG 图输出。BC1 18 张 200×44 文本图均完全不透明，不代表全库 BC1 无透明。

新增 summarize_swsh_texture_parity.py，读取实际 pixels.jsonl，按格式及 selector 分组，复核像素覆盖和 Alpha 差值直方图，统计 Alpha exact/different、RGB different、可见及隐藏差异、像素加权 MAE、重复组和缺失条目。运行：

```
python scripts/summarize_swsh_texture_parity.py artifacts/swsh-texture-parity/pixels.jsonl --out artifacts/swsh-texture-parity/format-report.json
```
