新增 pokemon_image_crosswalk.py：HOME 包中所有 Git 跟踪 PNG 逐一核对 Git blob 身份，按 PNG 实际 RGBA 字节计算 SHA256、透明像素清零后的额外视觉哈希、Alpha 统计及尺寸；保留 PNG 来源与颜色 metadata，不能将已有 PNG 验证冒充原生 BNTX 双解码。按 blob 缓存解码但保留每条资产路径。固定 HOME commit 9fa10809a23e1fc8d5b6987d77112c2cfe1ff9fb。

```bash
python scripts/pokemon_image_crosswalk.py home-scan --root ../PokeHome_Resources --out artifacts/home-pixels
python scripts/pokemon_image_crosswalk.py join --swsh artifacts/swsh-texture-parity/pixels.jsonl --home artifacts/home-pixels/home_pixels.jsonl --za ../ZA_Resources/.za-work/bntx/textures.jsonl --za-commit <实际ZA解码提交> --out artifacts/pokemon-image-index
```
