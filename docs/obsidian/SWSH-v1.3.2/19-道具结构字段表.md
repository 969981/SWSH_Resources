# Item8 结构与提取算法

`item.dat` 的索引头：`u16 count @0x00`、`u16 max_index @0x04`、`i32 entries_start @0x40`，`u16 entryIndex[count] @0x44`。第 N 个道具的真实记录偏移是 `entries_start + entryIndex[N] * 0x30`，**不是** `0x44 + N * 0x30`。

记录 0x30：`Price u32 @0x00`、`PriceWatts u16 @0x04`、`PriceAlternate u16 @0x08`、`Pouch nibble @0x11`、`EffectField @0x13`、`CanUseOnPokemon @0x15`、`ItemSprite u16 @0x1A`、`GroupType @0x1C`、`GroupIndex @0x1D`、`Boost0..3 @0x1F..0x22`。

对所有输入长度和 entryIndex 检查越界，保留读取位置、源 SHA256；对非零价格的异常项核对 UI 数据。结构实现：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Structures/Item/Item8.cs)。
