## NativePokemonIconSelector
直接读取 personal_total.bin (209792 bytes,1192*0xB0), +0x1E form stats index, +0x20 count, +0x21 bit6 present, +0x4C model token；base national index 1..898，alternate form ptr+form-1。与 pokecaplist 原版 <HHHBB> 逐条关联：882 非特殊记录均唯一物种/形态，2 条 0000 special，0 unresolved。973 -> 855 (form 0 index855, form1 index1173); 983 -> 892。参考 [PKHeX PersonalInfo8SWSH](https://github.com/kwsch/PKHeX/blob/master/PKHeX.Core/PersonalInfo/Info/PersonalInfo8SWSH.cs) 字段布局，+0x4C 实测为模型资源 token，不直接当 national species。保留 gender_raw/variant_raw，runtime_verified=false。2 个 0973 s 别名未在 caplist 中，不提升证据。

## BallImageMapping
26 条 pouch=1/group_type=1，group index 0..25，ItemID 1..16,492..499,576,851；sprite=ItemID。group+1 与 [PKHeX Ball enum](https://github.com/kwsch/PKHeX/blob/2c541ad4225afde40082e71838baf127bd96cead/PKHeX.Core/Game/Enums/Ball.cs) 1..26 顺序一致。静态表与外部枚举相符，不等于已恢复原生转换函数。BallID 标记 candidate，继续追踪 ELF item group consumer。

## RibbonMarkImageMapping
读取原版简中 ribbon.tbl：AHTB 295 records，header 8，entry 8 hash bytes + u16 string length + NUL-terminated string。mes_ribbon_name_001..100、mes_ribbon_info_001..100、mes_another_name_001..100 各98，缺73/74；1 extra msg_ribbon_max。源文件同样缺73/74，01/02 各 a/b 两变体，共100图标。编号与原版消息 key 一致；不将 resource_number 认作存档 RibbonIndex/MarkIndex。九语言逐表验证在新 Actions 中执行；译文 DAT 尚未解码。type typename.tbl 简中 19 keys，TYPENAME_000..018 缺009，18 项加 max。资源 token 与消息键顺序候选，未恢复消费者。
