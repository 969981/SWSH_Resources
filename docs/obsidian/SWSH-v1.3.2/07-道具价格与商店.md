# 道具列表、价格、图标与商店

`bin/pml/item/item.dat` 使用 `Item8.GetArray`：头部包含 `numEntries`、`maxEntryIndex`、`entriesStart`，每条映射的结构长度 0x30。记录相对偏移：`0x00 Price(u32)`、`0x04 PriceWatts(u16)`、`0x08 PriceAlternate(u16)`、`0x11 Pouch` 低四位、`0x13 EffectField`、`0x15 CanUseOnPokemon`、`0x1A ItemSprite(u16)`。

商品价格、BP 和瓦特价格是不同货币/字段，不能当作一个数。商店原始表 `bin/appli/shop/bin/shop_data.bin` 按 `ShopInventory → Single[]/Multi[] → Inventory.Items[]` 解析，商店 Hash/名称需要额外核对。

图片资源可在 `bin/appli/icon_item/item_*.bntx` 中查找；文件名与 item_id 的映射要验证而不是推断。[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Structures/Item/Item8.cs)。
