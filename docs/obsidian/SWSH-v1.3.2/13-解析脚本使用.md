# 重复提取与 CSV 输出

在仓库根目录执行：

```powershell
python scripts/export_swsh_catalog.py --root Unpack/v1.3.2/parsed --out Unpack/v1.3.2/catalog
```

生成：`species_personal.csv, moves.csv, evolution.csv, trainer_party.csv, trainer_held_items.csv, egg_moves.csv, summary.json`。只读取已经提交的解析 JSON，未解析的野生遭遇与静态锁闪**不会凭空出现在 CSV**。

源内容的 SHA256 与导出 JSON 的 SHA256是不同证据：CSV 的 `derived_sha256` 明确是解析后 JSON 哈希。文件 ID 从源文件名解析，内部形态行 ID 以 Personal 记录真实索引为准。

想扩展原始道具和等级习得：参考 `tools/pkNX/pkNX.Structures/Item/Item8.cs` 和 `Learnset8.cs`，先在真实源文件上验证，然后才增加导出器。
