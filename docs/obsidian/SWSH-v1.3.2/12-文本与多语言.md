# 多语言文本与中文名称映射

已有 `Unpack/v1.3.2/parsed/bin/message/<Language>/...`。源码语言目录有 `JPN,JPN_KANJI,English,French,Italian,German,Spanish,Korean,Simp_Chinese,Trad_Chinese`。 `TextFile(...,TextConfig(GameVersion.SWSH))` 导出每行 `index,flags,text`。

名称 JOIN 必须基于语义键/表名/一致文件布局，不能把不同文件的第 N 行假定是同一个物种或道具。推荐输出长表：`language,text_file,text_key,index,flags,text`，保留控制码与转义，不清洗掉未知字符。

[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Game/File/GameFileMapping.cs)。
