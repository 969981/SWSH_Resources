# PersonalInfo8SWSH 0xB0 记录布局

| 相对偏移 | 内容 |
|--|--|
| 0x00–0x05 | HP,ATK,DEF,SPE,SPA,SPD 各 u8 |
| 0x06–0x07 | Type1, Type2 |
| 0x08 | CatchRate |
| 0x0A | EVYield bitfield u16 |
| 0x0C,0x0E,0x10 | 野生携带道具条目 Item1/2/3 |
| 0x12 | 性别阈值 |
| 0x18,0x1A,0x1C | Ability1/Ability2/AbilityH u16 |
| 0x1E | FormStatsIndex u16 |
| 0x20 | FormCount |
| 0x21 | 颜色及 IsPresentInGame bit6 |
| 0x22 | BaseEXP u16 |
| 0x28–0x37 | TM 128 位 |
| 0x38–0x3B | Type tutor flags |
| 0x3C–0x4B | TR 128 位 |
| 0x4C | ModelID（源码 u32 读取后转 ushort） |
| 0x5E | Form u16 |
| 0xA8–0xAB | Armor tutor flags |
| 0xAC,0xAE | Armor/Crown Dex Index |

准确字段代码：[查看源码](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Structures/Personal/Info/PersonalInfo8SWSH.cs)。注意 `personal_total.bin.json` 是子集字段，CSV 不代表已保留完整 0xB0 所有字段。
