# 剑盾纹理解码和像素对账
入口：[[33-图片审计验收与原生图标选择]] · [[32-SWSHImageResourceAudit全量图片审计]]

## 基线和范围
Run 45767220283 解析 15407 BRTI；格式 BC1/2/3/4/5/7、RGBA8、R5G5B5A1。依据 BNTX-Extractor (https://github.com/aboood40091/BNTX-Extractor) 与 vendored Switch Toolbox，0x10 为 tile mode byte（此前 metadata 的 +0x12 实为 flags，原字段名保留作历史 raw 值）、0x34 block height log2，0x58 channel select，0x70 mip pointer table。保留 raw 原始参数；packed 0x0501 的位序需独立参考复核。
## 实现
- swsh_texture_decoder.py: BRTI 指针、块线性 GOB 或 pitch-linear、mip0 layer0、Pillow BC 解码，通道选择，PNG 无损往返验证。
- swsh_texture_parity_audit.py: texture2ddecoder BC1/3/4/5/7、独立标量 BC2、packed 参考、RGBA 原始字节检查；共享 deswizzle，不能称独立容器/解 swizzle 双实现；RGBA raw 不是独立压缩解码器。保留原始 RGB，包括全透明像素。
- 逐纹理 RGBA SHA256（行优先 RGBA8、无色彩转换、包含透明 RGB）、PNG SHA256、linear SHA256、尺寸、alpha 统计、RGB/A 最大和平均绝对差、Alpha 差值直方图、PSNR、可见像素差异；不虚构 SSIM 或预乘透明度结论。重复分组按 width/height/rgba_sha256。
- 数组、体积、特殊 layout 遇到明确失败，不用假图补齐。当前只覆盖 mip0 layer0，不代表全部 mip/array face；跨作品只定义兼容键，未对账 HOME/ZA 的实际数据。
- CI 完整 PNG 内存编码/重读，归档 metadata only；本地 --png 才落盘 PNG，禁止上传原版图片。
## 复现
```
python -m pip install numpy==2.2.6 Pillow==12.3.0 texture2ddecoder==1.0.6
python -m unittest discover -s tests -p test_swsh_texture_parity.py -v
python scripts/swsh_texture_parity_audit.py --verify-png
python scripts/swsh_texture_parity_audit.py --png
```
输出 artifacts/swsh-texture-parity/{summary.json,pixels.jsonl,duplicates.json,errors.json}。解码覆盖门与严格像素一致门分开；非零差异保留，不视为通过。CI 尚未验收。
