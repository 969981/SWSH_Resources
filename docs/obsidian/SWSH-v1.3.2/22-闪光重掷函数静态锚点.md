# 22 · Sword/Shield v1.3.2 闪光重掷函数静态锚点

源码：[\`ShinyRateSWSH.cs\`](https://github.com/969981/SWSH_Resources/blob/master/tools/pkNX/pkNX.Game/Editors/ShinyRate/ShinyRateSWSH.cs)。

- \`PRELUDE\` 是 pkNX 中的原始 ARM64 函数序列，搜索需要在 **NSO TEXT 解压后**进行。
- 从 \`v1.3.2/0/sword_main\` / \`shield_main\` 获取独立 BuildID、实际 SHA-256、TEXT 段 RVA 与解压状态。
- 实现：\`scripts/swsh_nso_shiny_probe.py\`；输出 \`Unpack/v1.3.2/catalog/nso_shiny_probe.json\`、\`nso_shiny_candidates.csv\`。
- 函数入口候选是 TEXT 匹配偏移加 TEXT RVA；两个内部指令点分别是入口 + \`0x2C8\`、+\`0x2CC\`，记录原始指令验证是否默认、NOP 或其他。
- 唯一匹配与哈希一致只证明**静态代码位置**，不是已验证运行时断点；重掷次数逻辑也不等于所有固定遭遇的 \`ShinyLock\` 实现。
- 动态确认：同 BuildID 的模拟器 GDB attach，核对 \`mainBase+RVA\` 和原始指令，分别触发普通野生、固定遭遇、活动巢穴，验证命中条件与 PID 结果；未验证前保持 \`STATIC_UNVERIFIED_RUNTIME\`。
