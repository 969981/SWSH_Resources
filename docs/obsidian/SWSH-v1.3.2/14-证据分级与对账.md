# 证据状态与验收条件

- `CONFIRMED`：真实字节、格式校验、可重复解析；含运行时意义时还需动态验证。
- `CANDIDATE`：路径/字段/结构具有线索，但语义、版本或名称关联尚未闭合。
- `UNKNOWN`：原始信息保留，不猜字段或地址。
- `REJECTED`：有反例或验证失败。

区分 `SOURCE_VERIFIED` / `EXTRACTED` / `STRUCTURE_ONLY` / `PARSED` / `SEMANTIC_VERIFIED`。元数据 WAV 的 `PARSED` 不代表音频转码；GFPak 子文件解包不代表遭遇表解码。
