## 数据关联

全部 372 张地区表均匹配到 SWSHInfo.Zones 英文地名，同时填充 ZoneLocations 的地图数值 ID 以及 ZoneType 的地区类型。地名保留 pkNX 源码英文原名，未经文本 ID 核对不编造中文翻译。

运行：python scripts/enrich_swsh_wild_encounters.py --repo .

输出位于 Unpack/v1.3.2/catalog/ 下：

- wild_encounters_enriched.csv：保留原来 35,960 行的所有字段，添加版本、明暗雷、地图 ID、地名、天气/活动中英名称和证据说明。
- wild_zone_index.csv：每版每模式每地区一条，合计372条，含等级范围、物种数、原始槽位数。
- wild_mapping_summary.json：源文件 SHA-256、版本限定物种交叉验证、地名覆盖率和验收统计。
